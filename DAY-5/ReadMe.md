## 📌 1. What are Operators?

In JavaScript, **Operators** are special symbols or keywords used to perform specific operations on variables and values (called operands).

### Core Syntax Example:
```javascript
let c = a + b; // '+' is the operator, 'a' and 'b' are operands


📚 2. Types of Operators in JavaScript
JavaScript supports 8 primary types of operators:

Arithmetic Operators: Used for mathematical calculations (+, -, *, /, %, **).

Assignment Operators: Used to assign values to variables (=, +=, -=).

Comparison Operators: Used to compare two values (==, ===, !=, >, <).

Logical Operators: Used to determine logic between variables/values (&&, ||, !).

Ternary (Conditional) Operator: Short-hand syntax for if-else conditions (condition ? expr1 : expr2).

Type Operators: Used to check or convert data types (typeof, instanceof).

Bitwise Operators: Performs operations at the binary bit level (&, |, ^, ~).

String Operators: Used to concatenate strings together (+, +=).


💡 Key Takeaways
Operators manipulate data stored in variables.

Combining variables with an arithmetic operator (+) calculates a new value dynamically inside a function.

Binding functions to interactive DOM elements (onclick) executes operator logic seamlessly upon user interaction.
